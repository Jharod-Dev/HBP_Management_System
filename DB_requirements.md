# Database Requirements
   
## 1. User Information
*Account information
    User ID
    First Name
    Last name
    Email address
    Password hash
    Account role (Admin or User)
    Last login date
    Age
*Customer profile information
    Name
    Email
    Age
*Account security information
    Email verification status OTP
    Password last changed date
    Password reset 
## 2. Unit Information
*Unit details
    Unit ID
    Unit name or number
    Unit type (Billiards or Karaoke)
    Unit category (Table 1 & 2 VIP, TABLE 3 & 4 Normal, Karaoke booth 1&2&3 etc.)
    Unit description
    Unit status (Available, Occupied, Unavailable)
*Unit configuration
    Minimum rental duration
    Whether reservations are allowed
    Unit-specific pricing reference
    Unit availability or operational status
## 3. Reservation Information
Reservation details
    Customer/User ID
    Reserved unit ID
    Reservation date
    Reservation start time
    Reservation end time
    Requested rental duration
    Reservation submission date and time
